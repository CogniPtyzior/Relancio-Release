# Relancio

Relancio is a local-first desktop application that helps users process incoming emails, prepare AI-assisted replies, review them, and send them manually.

The application is built with .NET and Avalonia. It is designed to keep the mail workflow under the user’s control: replies are proposed, editable, and never sent automatically.

## Main features

- Desktop email workflow for received and sent messages
- AI-assisted reply generation with local LLM support
- Manual review, editing, saving and sending of replies
- SMTP sending and POP3/IMAP reception configuration
- Optional web/mobile access for reviewing replies remotely
- Business kits support to adapt replies to specific professional contexts

## Downloads

Public builds are available from the GitHub Releases page.

### Windows

The Windows x64 build is the primary supported platform.

### Linux

A Linux x64 build is also provided, but it is less tested and may not include all features available on Windows.

## Business kits

Business kits can be downloaded from the release assets and imported from the Relancio desktop settings.
